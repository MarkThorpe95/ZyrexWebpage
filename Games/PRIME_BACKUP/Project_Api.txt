Boot Flow
1. index.html loads all files in js/core.
2. js/core/game.js reads MOD_PATHS and injects grouped mod scripts.
3. Mods call RSGame.Game.registerMod(...).
4. After save selection, game.js builds the Player and calls RSGame.Game.runHook("onGameInit", RSGame.Game).
5. game.js renders core UI and then calls RSGame.Game.runHook("onAfterRender", RSGame.Game).

Known Event Names In Use
- skillMenuSelect: emitted from ui.js when clicking a skill cell.
- xpGain: emitted by skill loops like woodcutting/mining.
- playerUpdated: used by GE, raids, pets, combat-related UIs.
- equipmentChanged: used by raids/minigames and other stat-sensitive UIs.
- inventoryRendered: used by fletching and duel inventory sync.
- gameSpeedChange: used by combat and skill systems.
- zoneLeave: emitted when leaving an activity.
- zoneActivityStart: emitted when beginning a zone activity.

Inventory And Equipment
- Inventory file: js/core/inventory.js
- Equipment file: js/core/equipment.js

- Coins/platinum token conversion handled in inventory.js, including overflow rollover when coins hit the 2,147,483,647 cap.

- Equipment bonus lookup is performed in ui.js using OSRS item mapping + OSRSBox item JSON.

Equippable Item Configuration
- Source of truth for equippable item data is the item payload passed to `inventory.addItem(...)` and the OSRSBox equipment mapping resolved by `js/core/inventory.js`.
- Valid equip slots: `head`, `cape`, `neck`, `weapon`, `body`, `shield`, `legs`, `hands`, `feet`, `ring`, `ammo`.
- Define equipment using OSRS wiki/OSRSBox item names and IDs so `fetchWikiIntel(...)` can resolve slot and bonus data automatically.
- `itemType` should be set to `Equipment` for equippable items, and `leftClickAction` should be `Wield` for weapon/ammo or `Wear` for armor/other slots.

| Item ID | Display Name | Equip Slot | Bonus Stats | Requirements | Notes |
|---|---|---|---|---|---|
| `bronze_sword` | Bronze sword | `weapon` | Attack bonuses from OSRSBox | Attack 1 | Standard wieldable weapon |
| `bronze_pickaxe` | Bronze pickaxe | `weapon` | Attack/Crush bonus from OSRSBox | Attack 1 | Also used as a mining tool |
| `iron_pickaxe` | Iron pickaxe | `weapon` | Attack/Crush bonus from OSRSBox | Attack 1 | Higher tool tier than bronze |
| `knife` | Knife | `weapon` | Attack bonus from OSRSBox | Attack 1 | Tool that can also be wielded |
| `leather_body` | Leather body | `body` | Defence bonuses from OSRSBox | Defence 1 | Starter armour piece |
| `hsr_item` | HSR ring | `ring` | Custom bonus values | Custom requirement | Custom ring item with `Equip Ring` action |
| `platinum_token` | Platinum token | — | Currency only | — | Not equippable |
| `divine_token` | Divine token | — | Currency only | — | Not equippable |

Notes:
- For new OSRS items, add the matching OSRS wiki name and icon file to the item definition, then set `slot` and optional `bonuses`/`requirements` in the item payload.
- If the OSRSBox equipment mapping resolves the item, `js/core/inventory.js` will auto-populate `slot`, `bonuses`, and `leftClickAction` from the wiki data.
- Use this table as the documentation schema for future equipment additions. If a custom item does not resolve via OSRSBox, provide explicit `slot` and `bonuses` in the item object.

Grand Exchange System
- File: js/mods/04_systems/07_grand_exchange.js
- Creates Exchange tab and panel.
- Uses prices.runescape.wiki price data.
- Stores GE cache in localStorage.
- Prices auto-refresh when a GE item is selected if the cached data is stale, removing the need for the manual refresh button.
- GE market prices refresh on a 4-hour schedule and then continue to be reused for subsequent offer creation.
- Offer price adjustments (+/- buttons) change only the submitted offer price, not the item's base market price.
- Used as the shared price source for bank values, combat loot value estimates, and drop party pool building.
